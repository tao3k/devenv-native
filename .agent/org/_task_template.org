** Notes

Lifecycle contract for agent-owned task headings:

- Keep a new planned task as =TODO= while no implementation work has started and progress remains =0%=.
- When an agent begins the task and the heading progress cookie moves above =0%=, change the heading keyword from =TODO= to =DOING=.
- When the heading reaches =100%=, change =DOING= to =DONE=, add an inactive =CLOSED: [YYYY-MM-DD Day]= timestamp after validation/evidence is recorded, and complete the =Closure Questions= table.
- Archive readiness requires all closure signals: =DONE= + =100%= + =CLOSED= + non-empty =Value= cells for every =Closure Questions= table row that has a =Question= value.
- After archive readiness is reached, move the task to the default archive path derived from the task source filename so completed work does not pollute active memory recovery.
- =wendao-client orgize lint= warns when these lifecycle/progress states drift.
